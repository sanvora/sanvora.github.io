How this chat works

On-Device AI Model

SmolLM2-360M-Instruct runs entirely in your browser via WebAssembly (ONNX Runtime Web). Your questions never leave your device — no server calls during inference.

Retrieval-Augmented Generation (RAG)

A curated knowledge base about Kham's portfolio is pre-embedded as 384-dimensional semantic vectors (all-MiniLM-L6-v2). Each question retrieves the most relevant context chunks before the model generates a response.

Output Guardrails

Every response is validated before display. Hallucinations, off-topic drift, and unsafe outputs are intercepted and replaced with a safe fallback — keeping answers grounded and on-topic.

Fine-tuning & distillation details

DRAG Fine-tuned Model

The DRAG Fine-tuned model in Compare mode is SmolLM2-360M trained via direct Supervised Fine-Tuning (SFT) on ~460 curated question-answer pairs generated by Llama 3.3 70B through Groq. The training uses completion-only loss masking so the model learns to answer grounded in retrieved evidence, not memorize prompts.

ONNX INT8 Quantization

After fine-tuning, the model is exported to ONNX and quantized to INT8 (~360 MB) for efficient browser inference. A custom post-processing step patches float16 scale tensors that ONNX Runtime Web rejects in the embedding layer's DequantizeLinear nodes.

Compare Mode

Use the Compare button to run Groq's Llama 3.3 70B (cloud API) side-by-side with the DRAG fine-tuned SmolLM2 (in-browser) — a live benchmark of what a 360M-parameter student learned from curated 70B-generated training data.
